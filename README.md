# socialbooth

## Panel admin

- `admin.php`: panel principal para ver eventos, progreso, rellenar y eliminar eventos.
- `admin_event.php?eventName=<evento>`: gestion por espacio/foto para restablecer imagenes individuales.
- `download_event_zip.php?eventName=<evento>`: descarga todo el contenido del evento en un archivo ZIP.

## Dependencias de PHP

- `ext-gd`: generacion y composicion de imagenes.
- `ext-zip`: descarga comprimida de eventos.
